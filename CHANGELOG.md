# Changelog

## 0.1.0

- Compare repositories with a base ref, starting from the merge-base or the selected ref directly.
- Browse changed files and commit history, including saved uncommitted changes and untracked files.
- Open read-only side-by-side diffs or review all visible changes in the multi-diff editor.
- Filter files by path and Git status, switch between folder and list views, and restore comparisons after restarting VS Code.
- Install the `git-diff-view` terminal command from the extension.
- Use the shared `git-diff-view` skill with Claude Code or Codex, with project installation as the default.
